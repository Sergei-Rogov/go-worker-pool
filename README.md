# Go Worker Pool

Пример реализации Worker Pool на Go для конкурентной обработки заданий с использованием горутин и каналов.

## Возможности

- Запуск нескольких воркеров в отдельных горутинах.
- Передача заданий через канал `jobs`.
- Получение результатов через канал `results`.
- Обработка ошибок для некорректных входных данных.
- Синхронизация горутин с помощью `sync.WaitGroup`.
- Отмена обработки через `context.Context`.

## Как работает

1. Программа создаёт пул воркеров.
2. Задания поступают в канал `jobs`.
3. Воркеры получают задания и обрабатывают числа.
4. Результаты передаются в канал `results`.
5. После завершения всех воркеров канал результатов закрывается.
6. Программа выводит результаты, количество ошибок и общую сумму.

Положительные числа умножаются на два. Для нуля и отрицательных чисел возвращается ошибка.

Порядок получения результатов может отличаться от порядка отправки заданий, поскольку обработка выполняется конкурентно.

## Запуск

bash
go run .


## Тестирование

bash
go test -v ./...


Тесты проверяют обработку положительных и некорректных значений, а также получение результатов от нескольких воркеров.

## Технологии

Go, goroutines, channels, sync.WaitGroup, context, testing.
